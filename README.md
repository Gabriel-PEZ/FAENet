# FAENet

**Work in Progress**

PyTorch reimplementation of FAENet, a geometric Graph Neural Network for materials modeling and physical property prediction using stochastic frame averaging.

**Reference paper:** [FAENet: Frame Averaging Equivariant GNN for Materials Modeling](https://arxiv.org/abs/2305.05577) (ICML 2023).

This project is part of the Geometric Data Analysis course of the MVA Master's program (ENS Paris-Saclay).

Implementation and experiments are currently in progress.
